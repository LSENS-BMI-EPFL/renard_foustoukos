# Exploratory analyses

Analyses written while developing the project: early versions of the
published analyses, controls that did not make it into the paper, and
illustrations. They are kept for reference only.

- They are **not needed** to reproduce the paper: use `pipeline/` and
  `figures/` (see the main README).
- They are **not maintained**. Many were written for older versions of the
  processed data and some no longer run; several write to hard-coded lab
  server paths.
- They use the same library (`fast_learning`), so they can be run in the same
  environment, from the repository root.
